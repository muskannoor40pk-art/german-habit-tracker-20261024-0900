### Overview
The Habit Tracker is a lightweight, browser-based productivity tool designed for individuals who value simplicity and data privacy. Tailored specifically for the DACH region (Germany, Austria, Switzerland), this application provides a clean, distraction-free interface to monitor your daily progress without the need for complex accounts or cloud dependencies.

### Features
*   **Weekly Overview:** Intuitive grid system to visualize your progress over the last seven days.
*   **Streak Counters:** Keep yourself motivated by tracking your current and longest habit streaks.
*   **Persistent Storage:** All data is saved directly in your browser using `localStorage`.
*   **Management:** Easily add new habits or remove them with a single click.
*   **Zero Dependencies:** Built entirely with vanilla technologies for maximum speed and security.

### Localization Notes
*   **Language:** The interface is localized for German-speaking users.
*   **Format:** Date and time formats follow the standard German (DE) convention (DD.MM.YYYY).
*   **Accessibility:** Designed for LTR (Left-to-Right) reading orientation, ensuring clear visual hierarchy for European users.

### Tech Stack
*   **Frontend:** HTML5, Modern CSS (Flexbox & Grid).
*   **Logic:** Vanilla JavaScript (ES6+).
*   **Persistence:** Browser LocalStorage API.
*   **Deployment:** GitHub Pages.
